入力補正で入力した文の、ほかの候補を出します。もう一度押すか ↑↓ で選んで、Enter で入れ替えます(Esc で閉じる)。入力のあとにカーソルを動かしていると、違うところが消えるので注意してください
 割り当てられるキー 使えるキーの組み合わせと、その理由 

割り当てたキーは、WhisperKey が起動している間、ほかのソフトでは使えなくなります。ふだんの文字入力に使うキーは選べないようにしています。

Ctrl か Alt を含む A〜Z、0〜9、Space、Enter、F1〜F24 と組み合わせられます。Shift を足してもかまいません
例: Ctrl + Space、Ctrl + Alt + R、Alt + Shift + F2
単体・Shift だけ F1〜F24 だけ選べます
例: F9、Shift + F10
使えないキー Esc、Tab、矢印キー、Windows キーなど。ほかのソフトが使用中のキーも割り当てられません

履歴の設定

オンの間、入力した文章を新しいものから 20 件まで残します。履歴はローカルファイルへ保存されます
入力履歴の消去
残っている履歴をすべて消します

音声辞書

聞き取った言葉を、入力する前に置き換えます。変換前は、聞き間違いやすい言い方をいくつでも登録できます

音声実行

話した言葉がキーワードと完全に一致したとき、入力する代わりに URL やファイルを開きます。判定は音声辞書で置き換えたあとの言葉で行うので、言い方の揺れは音声辞書にまとめられます

入力補正

聞き間違いをローカルの LLM で直します。入力までが少し遅くなります。入力履歴をオンにしてから使ってください
「、」「。」を LLM が付け直して、付き方をそろえます。入力までが少し遅くなります。いらない「、」「。」は設定タブで消せます
 よく使う言葉を追加学習 

補正の手がかりとして LLM に渡します。よみがなが空の言葉は使われません

使用するモデル

ダウンロードすると、入力補正をオンにできます

設定

入力モード

オンにすると、音声入力のキーを押している間だけ録音します
オンにすると、入力する文の「。」を消します。最後の「。」は消し、文と文の間の「。」は半角スペースにします
オンにすると、入力する文の「、」をすべて消します

話し終わってから変換を開始するまでの時間

効果音

インストール先の assets\sounds に wav ファイルを入れると、ここで選べるようになります

効果音の前後に無音をつけて、イヤホンが音の頭を取りこぼさないようにします。機種によっては、この対策でも音の頭が切れることがあります。有線やスピーカーなら、オフにすると少し早く鳴ります
 外観 インジケーター・テーマ・窓の位置 
画面に浮かぶ録音の目印。操作パネルなら、マウスで録音・取り消し・プッシュトゥトークの切り替えができます
窓の位置を元に戻す
インジケーターと候補の窓を、はじめの位置に戻します。モニターを外したときなど、見つからなくなったときに使ってください
 Windows との連携 クリップボードの履歴・Windows の起動時に立ち上げる 
